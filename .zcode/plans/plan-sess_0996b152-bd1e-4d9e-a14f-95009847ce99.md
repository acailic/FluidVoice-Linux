# Make SayItErmano feel like the macOS app — or better

TLDR: The port already matches macOS on structure (pill, tray, settings, history, command mode). What still makes the Mac app *feel* different is (1) instant streaming text in the pill, (2) a handful of shortcut/dictionary conveniences, (3) stats/motivation UI. Plan: ship an **"Instant pill" phase** (streaming preview, brief already written) plus a **parity quick-wins pack**, then keep the leapfrog menu (unix-socket API, AT-SPI, n-best) and the strategic picks (Wayland P3, command-mode v2 P5) documented for the next cycle. First deliverable is a committed idea/design doc — the "ideas" you asked for — then implementation.

## The idea catalog (the actual ideas, grouped)

**A. Feel — make it feel like the Mac app (recommended first)**
- **A1 Streaming live preview.** Today the pill previews text at ~1.2 s cadence and only with faster-whisper; the Mac shows words in <100 ms. `requests/streaming-finalization.md` already briefs phase 1: fixed 2 s windows / 50% hop, incremental decode with rolling `initial_prompt`, constant-cost assertion, energy+ZCR VAD early-stop; final transcript stays a full-take decode. Plus: generalize `PreviewEngine` so whisper.cpp and Parakeet backends get preview too (currently FW-only, `daemon.py:1269`). Effort M, low risk — no new engines needed.
- **A2 Pill hover chips (stretch).** Mac shows hover chips during recording: prompt selector, mode switcher, reprocess-last / copy-last / paste-last / undo-AI. X11 override-redirect windows can take pointer input without focus, so this is feasible; riskiest visual item, ship last.

**B. Parity — features the Mac app has that we lack (each S–M, independently shippable)**
- B1 Up to **3 dictation shortcuts** (keyboard or mouse) with **per-shortcut prompt profile** — Mac's killer convenience: "hold button 8 = terse notes, Right_Control = polished email". Config + `hotkey.py` + settings UI.
- B2 **Paste-Last-Transcription hotkey** + tray/action parity; also **undo-AI / reprocess-last** actions (history already stores `raw` + `ai`, so reprocess is cheap).
- B3 **Activation mode "both"** (toggle + hold active simultaneously, disambiguated like upstream `HotkeyActivationMode`); today it's toggle XOR hold.
- B4 **Dictionary spoken-formatting actions**: trigger word → insert new line/paragraph/tab/punctuation (upstream v1.6.9); our dictionary does plain replacement only (`processing/dictionary.py`).
- B5 **Spoken slash/mention grammar**: "slash fix", "at sign John", "tag John" (only literal `/ fix` + `@ John` squeeze ported; `processing/slash.py`).
- B6 **Stats page**: streak, time-saved (WPM-based), 7/30-day activity chart, milestones — Mac's StatsView. We already have today-stats + `history.jsonl` data; extend `gtkui` with a Stats page.
- B7 (small) Spoken-send **quiet-countdown** — gated on A1's VAD, noted inside A1's spec as follow-up. SFX independent-volume row.

**C. Exceed — things macOS doesn't have (documented for next cycle, not built now)**
- **Scriptable unix-socket API** — Mac ships a local HTTP API; we can beat it within our locked no-TCP scope by exposing `/transcribe`, `/history`, `/toggle` routes on the existing control socket (scriptable, sandbox-friendly).
- **AT-SPI caret-context smart typing** — context-aware caps/GAAV like Mac's AX, plus insertion fallback; unblocks "smart capitalization".
- **n-best pick lists** — upstream has *none* (single-best only); blocked until a backend exposes alternates.
- **Per-app behavior profiles** unifying prompt rules + insertion mode + terminal rules (we already have the pieces scattered).
- **Diarization** for file transcription; **command-mode v2** (P5, brief exists); **Wayland** (P3, brief exists — the docs' own strategic recommendation for reach).

**Won't do (locked):** notch UI (N/A on Linux), TCP/HTTP listener, dual UI, mascot art, telemetry, changing pill geometry/mode accents, autonomous command execution.

## Sequencing — options considered
1. **A → B (recommended):** A1 is the single most Mac-defining trait and is fully briefed; B items are low-risk palate-cleansers shipped between/after, matching the established proposals-menu rhythm.
2. B first, A after — more visible breadth sooner, but leaves the biggest "feel" gap open longest.
3. Strategic fork now (Wayland P3) — biggest user multiplier but doesn't make the app feel more like macOS; recommend it as the *next* cycle after this one.
